Bun

Bun は 2026 年に、実装言語を Zig から Rust に移しました。約 53.5 万行の Zig のコードの移植を、主に Claude Code が行い、人が書くなら 1 年かかる見積もりの作業を約 4 か月で終えたと報じられています。作者は「既存のテストの 99.8% が Linux x64 glibc で Rust 版でも通る」と発表しました。

報道どうしで食い違う点があります。

  • マージの日付: 2026-05-11 とする記事と、2026-05-14 とする記事がある
  • Rust 版の行数: 約 78 万行とする記事と、100 万行を超えるとする記事がある
  • Rust 版を含むリリース: 1.4.0 を 2026-07 とする記事と、2026-08 とする記事がある（GitHub のリリースは 2026-08-20。下の表）

Zig の作者が批判を公表するなど、反応は割れています（経緯の解説、論考）。

Rust 版になった版（リリースのタグで確認）

GitHub のリリースのタグで、Zig と Rust のビルド定義の有無を見ました。

Deno

中核（ランタイム・CLI・V8 との結合）は Rust で、標準ライブラリと Node.js 互換層は TypeScript と JavaScript で書かれています。言語の構成はいまも変わっていません。

ごく初期（2018 年ごろ）は Go で書かれていて、のちに Rust に移ったと記憶しています。今回は確かめていません。

Node.js

中核は C++ で、V8 と libuv を同梱しています。node:fs などの標準ライブラリは JavaScript です。全体を別の言語へ移す動きは見当たりませんでした。

依存の一部に Rust が入り始めているという話は聞いたことがありますが、今回は確かめていません。
