| ランタイム | 中核の言語 | 移り変わり |

## 2. Bun

Bun は 2026 年に、実装言語を Zig から Rust に移しました。約 53.5 万行の Zig のコードの移植を、主に Claude Code が行い、人が書くなら 1 年かかる見積もりの作業を約 4 か月で終えたと[報じられています](https://www.infoq.com/news/2026/09/bun-AI-rewrite-zig-rust-4-months/)。作者は「既存のテストの 99.8% が Linux x64 glibc で Rust 版でも通る」と発表しました。

報道どうしで食い違う点があります。

- マージの日付: 2026-05-11 とする記事と、2026-05-14 とする[記事](https://www.theregister.com/devops/2026/05/14/anthropics-bun-rust-rewrite-merged-at-speed-of-ai/5240381)がある
- Rust 版の行数: 約 78 万行とする記事と、100 万行を超えるとする[記事](https://xenospectrum.com/en/bun-zig-rust-rewrite/)がある
- Rust 版を含むリリース: 1.4.0 を 2026-07 とする記事と、2026-08 とする記事がある（GitHub のリリースは 2026-08-20。下の表）

Zig の作者が批判を公表するなど、反応は割れています（[経緯の解説](https://blog.nidhin.dev/why-bun-is-leaving-zig-the-full-story-of-the-rust-rewrite)、[論考](https://www.lesswrong.com/posts/qEbqPitYhWHthwFNu/bun-s-migration-from-zig-to-rust-as-a-potential-case-study)）。

### Rust 版になった版（リリースのタグで確認）

GitHub のリリースのタグで、Zig と Rust のビルド定義の有無を見ました。

| 版 | リリース | `build.zig` | `src/main.zig` | `Cargo.toml` | 実装 |
|---|---|---|---|---|---|
| 1.3.14 | — | あり | あり | なし | Zig |
| 1.4.0 | 2026-08-20 | なし | なし | あり | Rust |

この比較検証で測った Bun（1.4.0・1.4.3・1.4.4）は、すべて Rust 版です。結果レポートと計画書の記述もそれに合わせています。

## 3. Deno

中核（ランタイム・CLI・V8 との結合）は Rust で、標準ライブラリと Node.js 互換層は TypeScript と JavaScript で書かれています。言語の構成はいまも変わっていません。

ごく初期（2018 年ごろ）は Go で書かれていて、のちに Rust に移ったと記憶しています。今回は確かめていません。

## 4. Node.js

中核は C++ で、V8 と libuv を同梱しています。`node:fs` などの標準ライブラリは JavaScript です。全体を別の言語へ移す動きは見当たりませんでした。

依存の一部に Rust が入り始めているという話は聞いたことがありますが、今回は確かめていません。
