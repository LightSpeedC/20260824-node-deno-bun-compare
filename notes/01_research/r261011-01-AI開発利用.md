## 2. Node.js

### 方針の文書

リポジトリに [AGENTS.md](https://github.com/nodejs/node/blob/main/AGENTS.md) があり、AI エージェントを使うときの決まりを定めています。README に載っているコラボレータは注意して使ってよく、新しい貢献者は使わないよう求めています。

- 人がすべてのコミットに sign-off し、PR を出した人が全責任を負う
- AI の支援は `Assisted-by: <エージェント名>` で開示する。エージェント名義の sign-off・co-author は付けない
- エージェントを無人で動かさない。人の関与なしの push・PR・Issue・コメントは禁止
- テストを人の判断なしに消したり変えたりしない
- 違反すると PR のクローズ、ツールのブロック、投稿禁止がありうる

### 時期と議論

方針の PR [#62105](https://github.com/nodejs/node/pull/62105) は 2026-03-04 に作られ、2026-08-12 にマージされました。議論では LLVM の AI ツール方針を手本にする案が出た一方、LLM が生成したコードは出どころとライセンスが分からないという反対もありました。TSC の投票（nodejs/TSC#1831）と OpenJS Foundation の理事会にも諮られています。投票の結果は未確認です。

コアへの AI コードの禁止を求める署名活動もありました（[change.org](https://change.org/p/no-ai-code-in-node-js-core)）。約 1.9 万行の PR がきっかけとされています。検索結果の要約から得た情報で、ページ本体は確かめていません。

## 3. Deno

[CONTRIBUTING.md](https://github.com/denoland/deno/blob/main/.github/CONTRIBUTING.md) の冒頭に、AI ツール（Copilot・ChatGPT・Claude・Cursor など）で書いた貢献は PR の説明で開示するよう書かれています。

- 使うこと自体は罰しない
- 開示せずに使った疑いのある PR は却下する
- 中身の無い AI 生成の Issue・PR・コメントを大量に出すと、アカウント停止がありうる

開発チーム自身が AI を使っているかを示す痕跡（ボットのアカウント、エージェントの設定ファイルなど）は調べていません。

## 4. Bun

リポジトリに [CLAUDE.md](https://github.com/oven-sh/bun/blob/main/CLAUDE.md) があります。中身は、ビルドとテストの手順、コードの構成、PR の作法をまとめた開発ガイドです。レビューの基準として `REVIEW.md` と `.claude/docs/landing-prs.md` を参照しています。Claude 系のエージェントを開発に使っている強い状況証拠ですが、コミットや PR の上での実際の度合いは確かめていません。

Anthropic は 2025-12-03 に Bun の買収を[発表](https://www.anthropic.com/news/anthropic-acquires-bun-as-claude-code-reaches-usd1b-milestone)しました。それ以前から数か月の協業があり、Claude Code のインフラとネイティブインストーラーに Bun が使われていました。買収後も MIT ライセンスのオープンソースを続けるとしています。この発表では、Bun 自身の開発に AI を使うとは述べていません。
